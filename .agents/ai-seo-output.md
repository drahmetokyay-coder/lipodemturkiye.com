## 5. İçerik Yapısı: Answer Capsule Sistemi

### 5.1 Answer Capsule Nedir?

AEO optimize makalelerinde zaten kullanılan kalıp: Her H2 başlığının hemen altında, 40-60 kelimelik, bağımsız olarak çıkarılabilir, doğrudan cevap veren kalın paragraf.

**Örnek (aeo-optimized-articles.md'den):**

```markdown
## Lipödem nedir ve nasıl tanımlanır?

**Lipödem, vücudun belirli bölgelerinde -- özellikle bacaklarda ve bazen 
kollarda -- simetrik, orantısız ve ağrılı yağ birikimi ile kendini gösteren 
kronik bir hastalıktır. Diyete ve egzersize dirençlidir; ne kadar kalori 
kısıtlaması yaparsanız yapın, etkilenen bölgelerdeki yağ azalmaz.**
```

### 5.2 Answer Capsule Kuralları (Site Geneli)

| Kural | Detay |
|-------|-------|
| Her H2 altında 1 capsule | Tüm makale ve rehber sayfalarında |
| 40-60 kelime | Optimal AI çıkarma uzunluğu |
| Bağımsız anlam | Bağlam olmadan anlaşılabilir |
| Kalın format | `**...**` ile vurgulu |
| Birinci paragraf | H2'nin hemen altında, açıklama metninden önce |
| Doğrudan cevap | Soruyu doğrudan yanıtlar, giriş cümlesi yok |
| Aktif dil | "dır/dır" yapısı, edilgen değil |

### 5.3 Sayfa Tiplerine Göre Answer Capsule Uygulaması

| Sayfa Tipi | Answer Capsule | Örnek |
|------------|---------------|-------|
| Pillar makale | Her H2'de (12-15 capsule/sayfa) | Tamamlandı (6 pillar) |
| Cluster makale | Her H2'de (6-10 capsule/sayfa) | Yapılacak |
| Şehir sayfası | H1 altında 1 şehir capsule'ü | "İstanbul'da X klinik ve Y doktor lipödem tedavisi sunmaktadır..." |
| Karşılaştırma sayfası | Giriş capsule + sonuç capsule | "[A] vs [B] karşılaştırmasında..." |
| Araç sayfası | Araç tanım capsule'ü | "Lipödem Semptom Testi, 12 bilimsel kritere dayalı..." |
| Blog yazısı | Her H2'de | Standart makale formatı |

### 11.3 dateModified Stratejisi

AI motorları güncel içeriği tercih eder. `dateModified` schema alanı kritik.

```typescript
// Article schema'da dateModified
{
  "@type": "Article",
  "datePublished": "2026-06-01T00:00:00+03:00",
  "dateModified": "2026-06-15T00:00:00+03:00",  // Son gerçek güncelleme
  // ...
}
```

**Kural:** `dateModified` sadece gerçek içerik güncellemesinde değiştirilmeli, otomatik ISR revalidation'da değil. Sahte güncellik manipülasyonu Google tarafından cezalandırılabilir.
